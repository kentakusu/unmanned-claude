# 無人で動くときの原則

AI に無人で作業させるときの原則をまとめたもの。`CLAUDE.md` が本体。

## この文書が何か

人の逐次承認を待たずに最後まで実行させる運用で、実際に踏んだ失敗から抽出した原則。
大半は「測り方」と「報告の作法」に関するもの。

- 測る（根拠にしないもの・対照の取り方・件数の出し方・時刻・照合）
- 検査とガードを作る（緑を疑う・対象集合・片方向・在ると効いている・誘因）
- 書く／渡す・受け取る／変える
- 並んで働く（3 つの道具・望む状態と実際・記憶・連絡・人の画面と無人の文脈）

3 つの道具は、結（長く生きる共有の記憶）・紡（セッションを起こし、生かし、指示を渡す）・
渡（人の操作と AI の操作を互いに渡す。作りかけ）。名前と役割だけを書き、設定の値は書かない。
- 越えてはいけない一線／認証情報／この文書の育て方

## この文書に書かないこと

環境ごとの値は書かない。パス・ポート・名前・相手の事情・道具固有の手順は、
知識ベース側に置く。固有名詞が入りはじめたら、置き場所を間違えている。

実例・事故の経緯・発見の物語も書かない。必要なら履歴に残す。
行が増えるほど、引かずに踏み直す確率が上がるため。

## 使い方

この文書は「踏む前に止める」力を持たない。効くのは「測り方を決めるとき」に引く場合で、
手を止めるのは件数と、自分が別に測った値のほう。

規則を足すときは「打つ 1 行」の形にして、その作業をする場所に置く。
ここに書いてある 1 行は、打つときに開いていない。
